# 03_Music

[简体中文](README_ZH.md)

## Features

Music playback。

## Hardware Requirements

ESP32-S3-ePaper-3.97 and a USB data cable.

## How to Run

Run `idf.py set-target esp32s3`, then `idf.py flash monitor` from the project directory.

## Expected Results

Observe the display, serial output, or audio for the music playback demonstration.
