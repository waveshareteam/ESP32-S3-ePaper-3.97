# 04_SD_Test

[简体中文](README_ZH.md)

## Features

SD card access。

## Hardware Requirements

ESP32-S3-ePaper-3.97 and a USB data cable. A microSD card is required.

## How to Run

Run `idf.py set-target esp32s3`, then `idf.py flash monitor` from the project directory.

## Expected Results

Observe the display, serial output, or audio for the sd card access demonstration.
